Scientific computing provides the computational foundation for modelling, simulating, identifying, and interpreting engineering systems. In this research theme, numerical methods, mechanics, and machine learning are combined to develop reliable computational tools for civil and structural engineering.

This theme is suitable for students interested in finite element methods, numerical modelling, inverse problems, PDEs, scientific machine learning, and computational mechanics.

---

## Project Directions

<div class="research-grid">

<div class="research-card">

### Scientific Machine Learning for Engineering Problems

Develop computational methods that combine numerical simulation, governing equations, and machine learning for engineering applications.

**Suitable for:** PhD / M.Tech  
**Methods:** numerical methods, PDEs, neural networks, scientific ML, Python/MATLAB  
**Expected outcomes:** computational frameworks for solving or identifying engineering system models

</div>

<div class="research-card">

### Finite Element Modelling and Inverse Problems

Develop finite element-based computational models and inverse methods for identifying material, structural, or system parameters.

**Suitable for:** PhD / M.Tech  
**Methods:** FEM, optimization, inverse modelling, numerical linear algebra, uncertainty quantification  
**Expected outcomes:** model-updating and inverse-analysis tools for structural engineering applications

</div>

<div class="research-card">

### Computational Tools for Structural Dynamics

Develop simulation and visualization tools for structural dynamics, vibration response, wave propagation, and dynamic system analysis.

**Suitable for:** M.Tech / B.Tech / PhD  
**Methods:** MATLAB/Python, numerical integration, FEM, modal analysis, signal processing  
**Expected outcomes:** reusable computational tools, demonstrations, and research-grade simulation workflows

</div>

</div>
